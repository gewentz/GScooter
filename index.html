Como rodar localmente no seu computador / celular:
  1. Baixe ou salve este arquivo como index.html em uma pasta.
  2. Abra o terminal nessa pasta e inicie um servidor HTTP local:
    python3 -m http.server 8000
  3. Abra o Google Chrome e acesse: http://localhost:8000 (o endereço localhost é considerado ambiente seguro nativo).
